# Security

An input method sees every key you type, so security reports matter to us.

## Report a problem

Report a security problem privately on GitHub: open the **Security** tab of [anxuanng/oh-key](https://github.com/anxuanng/oh-key/security) and pick **Report a vulnerability**. Do not open a public issue for it.

We reply as soon as we can and say what we will do.

## What is in scope

- Anything that sends, stores or logs typed text. oh-key must do none of these.
- The keyboard hook in the app and what it does with the keys it sees.
- The release files, their SHA-256 sums and `install.ps1`.

## Supported versions

Only the latest release gets fixes.
