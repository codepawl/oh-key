2.0 Standard char set (the hub of everything)
StdVnChar = 0x10000 + index (VnStdCharOffset). 213 chars: 186 alphabetic + 27 "western symbols" (index 186..212 = bytes 0x80,0x82,0x83,0x84,0x85,0x86,0x87,0x88,0x89,0x8A,0x8B,0x8C,0x8E,0x91..0x9C,0x9E,0x9F that charsets repurpose; only needed for legacy charsets). Index layout, upper case at EVEN index, lower at ODD, tone t adds 2*t (each vowel family = 12 slots: A,a,A1,a1,...,A5,a5):
A 0-11 | Â 12-23 | Ă 24-35 | B36 b37 C38 c39 D40 d41 | Đ42 đ43 | E 44-55 | Ê 56-67 | F68 f69 G70 g71 H72 h73 | I 74-85 | J86 j87 K88 k89 L90 l91 M92 m93 N94 n95 | O 96-107 | Ô 108-119 | Ơ 120-131 | P132 p133 Q134 q135 R136 r137 S138 s139 T140 t141 | U 142-153 | Ư 154-165 | V166 v167 W168 w169 X170 x171 | Y 172-183 | Z184 z185.
This is the enum VnLexiName (vnl_A, vnl_a, vnl_A1, ... vnl_Z, vnl_z; vnl_nonVnChar=-1, vnl_lastChar=186). Two derived tables: StdVnNoTone[i] = index of same letter with tone 0 (keeps circumflex/breve/horn), StdVnRootChar[i] = base letter with ALL marks removed (Â,Ă->A; Ê->E; Ô,Ơ->O; Ư->U; Đ->D). In Rust: struct Letter{base:u8 family, tone:u8, upper:bool}; no tables needed.

2.1 VowelSeq table (VSeqList). Columns: seq | complete(C) | conSuffix(S: may be followed by a final consonant) | roof: pos of the circumflex letter if present, or "->X" the seq you get by adding a circumflex | hook: pos of horn/breve letter if present or "->X" seq by adding horn/breve (hook here also means breve "bowl"). Lowercase; case is carried separately.
Singles (all C=1,S=1): a (roof->ar, hook->ab) | ar (roofPos0, hook->ab) | ab (hookPos0, roof->ar) | e (roof->er) | er (roofPos0) | i | o (roof->or, hook->oh) | or (roofPos0, hook->oh) | oh (hookPos0, roof->or) | u (hook->uh) | uh (hookPos0) | y.
Doubles (C,S): 
ai 1,0 | ao 1,0 | au 1,0 roof->aru | ay 1,0 roof->ary | aru 1,0 roofPos0 | ary 1,0 roofPos0 | eo 1,0 | eu 0,0 roof->eru | eru 1,0 roofPos0 | ia 1,0 | ie 0,1 roof->ier | ier 1,1 roofPos1 | iu 1,0 | oa 1,1 hook->oab | oab 1,1 hookPos1 | oe 1,1 | oi 1,0 roof->ori hook->ohi | ori 1,0 roofPos0 hook->ohi | ohi 1,0 hookPos0 roof->ori | ua 1,1 roof->uar hook->uha | uar 1,1 roofPos1 | ue 0,1 roof->uer | uer 1,1 roofPos1 | ui 1,0 hook->uhi | uo 0,1 roof->uor hook->uho | uor 1,1 roofPos1 hook->uoh | uoh 1,1 hookPos1 roof->uor hook->uhoh | uu 0,0 hook->uhu | uy 1,1 | uha 1,0 hookPos0 | uhi 1,0 hookPos0 | uho 0,1 hookPos0 hook->uhoh | uhoh 1,1 hookPos0 | uhu 1,0 hookPos0 | ye 0,1 roof->yer | yer 1,1 roofPos1.
Triples: ieu 0,0 roof->ieru | ieru 1,0 roofPos1 | oai 1,0 | oay 1,0 | oeo 1,0 | uay 0,0 roof->uary | uary 1,0 roofPos1 | uoi 0,0 roof->uori hook->uhoi | uou 0,0 hook->uhou | uori 1,0 roofPos1 hook->uohi | uohi 0,0 hookPos1 roof->uori hook->uhohi | uohu 0,0 hookPos1 hook->uhohu | uya 1,0 | uye 0,1 roof->uyer | uyer 1,1 roofPos2 | uyu 1,0 | uhoi 0,0 hookPos0 hook->uhohi | uhou 0,0 hookPos0 hook->uhohu | uhohi 1,0 hookPos0 | uhohu 1,0 hookPos0 | yeu 0,0 roof->yeru | yeru 1,0 roofPos1.
"complete=0" means an intermediate form that is only legal once the marking key arrives (ie, ue, uo, eu, uu, uay, uoi... ) : with spell check on, such a vowel group at word end counts as non-Vietnamese (see lastWordIsNonVn); tone keys are refused on incomplete groups when spellCheck && !freeMarking. The sequence of vowels in a word is exactly the key into this table (case/tone stripped via StdVnNoTone); a 4th vowel or any pair not in the table = non-Vietnamese.

2.2 ConSeq table (CSeqList), "suffix" = may be a final consonant: b, c(suffix), ch(suffix), d, dd(đ), dz, g, gh, gi, gin, h, k, kh, l, m(suffix), n(suffix), ng(suffix), ngh, nh(suffix), p(suffix), ph, q, qu, r, s, t(suffix), th, tr, v, x. (so finals = c ch m n ng nh p t; "gi" and "gin" are initial clusters: "gi" is g+i where i is consumed as consonant, "gin" lets "gi"+"n" survive as a cluster, see 3.6; "qu" is q+u). Note z, f, j, w are not valid Vietnamese consonants: they classify as non-Vietnamese letters (chType NonVn) but still reach tone/hook processing via key maps. "dz" is accepted as initial (not final). 'r' also initial only.

2.3 Validity (isValidCV, isValidVC, isValidCVC)
- isValidCV(c, v): nil args => true. false if c==gi and first vowel is i (no "gii"), or c==qu and first vowel is u. If c==k: only these vowel seqs are legal: e, i, y, er, eo, eu, eru, ia, ie, ier, ieu, ieru. Otherwise true (so "ca" "ke" mismatches like "ci"/"ce"/"ngi" are NOT rejected; only k is). 
- isValidVC(v,c): true if either nil. false if !v.conSuffix or !c.suffix. Else (v,c) must be in VCPair list:
 a: c ch m n ng nh p t | ar: c m n ng p t | ab: c m n ng p t
 e: c ch m n ng nh p t | er: c ch m n nh p t
 i: c ch m n nh p t
 o: c m n ng p t | or: c m n ng p t | oh: m n p t
 u: c m n ng p t | uh: c m n ng t
 y: t
 ie: c m n ng p t | ier: c m n ng p t
 oa: c ch m n ng nh p t | oab: c m n ng t
 oe: n t
 ua: n ng t | uar: n ng t
 ue: c ch n nh | uer: c ch n nh
 uo: c m n ng p t | uor: c m n ng t | uho: c m n ng p t | uhoh: c m n ng p t
 uy: c ch n nh p t
 ye: m n ng p t | yer: m n ng t
 uye: n t | uyer: n t
 (anything else false; e.g. no "an"+... see table; "ang" with ar absent; "er"+ng absent; "oh"+c/ng absent; "uh"+p absent)
- isValidCVC(c1,v,c2): if v nil: true iff (c1 nil) or (c2 not nil). If c1 nil: isValidVC. If c2 nil: isValidCV. Else true iff isValidCV && isValidVC; exceptions where VC fails but CVC passes: (c1==qu, v==y, c2 in {n,nh}) -> "quyn/quynh"; (c1==gi, v in {e,er}, c2 in {n,ng}) -> "gieng/giêng". Spell check = that function over (initial, vowel seq, final).

====================================================================
3. ALGORITHM
====================================================================
3.0 State. A word buffer (max 128 entries, shared across words with a "word break" entry as separator; when it nears full, drop the oldest half but only at a word break). Each entry: keyCode, base letter (vnSym, tone-stripped, lowercase), caps flag, tone, plus parse info: form in {nonVn, empty(=word break), c, v, cv, vc, cvc}, offsets to the initial cluster / vowel group / final cluster entries, and for each position the sub-sequence (cseq or vseq) ending at it. Engine options: freeMarking (default on), modernStyle (default off), spellCheckEnabled (default on), autoNonVnRestore (default off), macroEnabled (default off); vietKey on/off. Plus flags: singleMode (spell check suspended for this word), reverted, toEscape. A second buffer keeps raw keystrokes (128, each with `converted` flag). Output of one key = (backs = number of chars/bytes to delete before the cursor, text to type). Rust design recommendation: keep a Vec of letters for the current word; recompute (initial, vowel group, final) by one scan after every change; sticky `nonVn` flag per word; same observable result as the incremental C++ (word <= ~10 letters, cost negligible). Output as diff: find first changed position, emit backspaces = chars from there to the end of the old rendering, then new text from there (markChange does exactly this; in UTF-16/UTF-8 "chars" backs = char count, for legacy charsets = encoded byte count; UNIDECOMPOSED = bytes/2).

3.1 process(key): classify key via map -> event. If toEscape is pending (VIQR "\" escape): next key is appended raw. Dispatch to processTone/Roof/Hook/Dd/TelexW/MapChar/EscChar/Append. After dispatch: if vietKey && last entry form==nonVn && key chType==Vn && (spellCheck off || singleMode) -> processNoSpellCheck (restart parse at this letter as new one-letter v/c group so transformations keep working mid-"word"). Then record the keystroke with converted = (result handled && !restored). If result==0 the host passes the original key through unchanged.

3.2 processAppend (plain letter):
- Reset char -> clear buffer; WordBreak -> singleMode=false, processWordEnd (3.8). NonVn char -> new entry form nonVn (if the previous is nonVn/empty etc.).
- Vn letter: it's a VOWEL iff base in {a,e,i,o,u,y} incl. marked forms (đ not). Special: a 'u' right after a lone cs_q consonant and an 'i' right after a lone cs_g consonant are appended as CONSONANTS (making qu/gi). Else vowel/consonant append:
 appendVowel: prev form empty/start -> form v. prev nonVn/vc/cvc -> becomes nonVn (vowel after a final consonant kills the word). prev v/cv: extend vowel group: new group = lookupVSeq(old group + this vowel); not found or 3 already or (new letter carries its own tone while group already has a tone) -> nonVn. For cv also isValidCV(initial, newgroup). On success if a tone existed it is re-placed per tone-position rules (3.5) because the cluster changed; if the typed char itself carried a tone (Unicode input) that tone is placed too. prev c: group = single vowel; isValidCV(initial, v) else nonVn; special: if initial is gi and it held a tone, that tone moves to the vowel ("gi"+"a": gía->?).
 appendConsonant: prev nonVn -> nonVn. prev empty/start -> initial c. prev v/cv: final = lookupCSeq(letter); valid iff isValidCVC(initial, vowels, final); (special: vowels uo+ or u+o with a following final make "ươ": if group is uoh or uho and a final consonant is accepted, normalise both to ư+ơ: e.g. "muon"+... handled when typing 'n' after "uơ"/"ưo": ưo->ươ.) When final accepted the tone is re-placed with terminated=false (e.g. hóa -> hoán). Invalid -> nonVn. prev c/vc/cvc: extend cluster: lookupCSeq(prev cluster + letter) (3-letter clusters ngh, gin cannot extend); if in vc/cvc recheck isValidCVC; invalid -> nonVn.
 A nonVn word is sticky for the rest of the word: every later key just appends raw (all transform keys fall into processAppend since vOffset<0 / c1Offset<0).

3.3 Roof (a e o in Telex, 6/^ in VNI/VIQR): requires vowel group; vEnd/vStart from current entry's vOffset (so the final consonant is skipped: the target is the vowel group of the current word end, free marking => any position in the group). newVs = withRoof. Special: for uho, uhoh, uhoi, uhohi (u+o+...) pressing roof key makes u,ô (doubleChangeUO: u, or, rest). If withRoof==nil: if roofPos==-1 (group has no roof-able vowel) -> plain append; else a roof already exists -> UNDO: replace that vowel's mark (â->a, ê->e, ô->o) if (target==any or matches the existing roof letter); then the key letter is appended as a normal char and the word is marked "reverted" (this is the aaa -> aa behaviour). With specific target (Telex a/e/o): the new roof letter in withRoof must equal target, e.g. 'o' on "a" does not roof (-> "ao"). Validity: isValidCVC(initial, newGroup, final) must hold else append plain. If freeMarking is off, the change position must be the LAST char of the word (current), otherwise append plain. After changing, tone is moved if the tone position moved (3.5). The commented-out code that removed the tone on undo is intentionally disabled ("users don't like it").
3.4 Hook (w in simple telex, 7 8, + * ( ): same shape using withHook/hookPos. kind HookAll applies horn to u/o, breve to a (breve only when the group allows it, table above); Hook_uo (VNI 7, VIQR + *) must not apply to a (breve); Bowl (VNI 8, "(") only breve, Hook_u / Hook_o only that letter. Undo if already hooked (and key type matches): uw on ư -> u + raw key appended, reverted. uo/ươ handling (processHookWithUO) when vowel group has len>1 and starts with u|uh and second is o|oh|or (and key is not Bowl):
 - HookAll/Hook_uo on "uo","uor","uoi": -> both get horn: u+o+ (ươ). EXCEPTION: if group is exactly uo/uor ending at the cursor and initial is "th" ("thuo"): horn only on o -> "thơ"(u stays plain) i.e. tho + w -> thơ. Hook_u: u -> ư only (uh+o), Hook_o: o -> ơ only except the same "th" rule and u+o -> ươ when typed on u-o pair (v[0]==u: both become horn; if v[0]==uh then only o).
 - on "uho" (ưo) -> ươ; on "uoh" (uơ) -> ươ; on "uhoh" (ươ) HookAll toggles back to "uo" plain (hookRemoved => key appended raw, reverted).
 - If freeMarking off and not at end: append plain.
 Telex 'w' (processTelexW): try hook; if hook not applicable (returns 0), the key is re-interpreted as MapChar producing ư (or Ư if uppercase W; caps lock flips case): standalone "w" -> ư, "tw" -> tư. If that also fails (e.g. the mapped ư cannot follow, like after k or "au") the raw 'w' is kept. A second w when the previous char is the mapped ư undoes it: ư -> w raw ("ww" -> "w"). Implementation quirk: `usedAsMapChar` is a function-local static (shared across all engine instances/words); in the port make it per-word state (set true when w was mapped to ư, cleared when a hook succeeds). Same MapChar undo applies to "[" "]" "{" "}" keys ("]]" -> "]" ... ) and the MS-VI map: the mapped letter is appended; if the form is still valid keep; else step back; if the previous letter equals the mapped letter and form!=c -> remove it (tone re-placed) and append the raw key; reverted.
3.5 Tone placement (getTonePosition(vseq, terminated)): returns index inside the vowel group:
 1. len==1 -> 0.
 2. group contains a circumflex/roof letter (roofPos!=-1) -> that letter (e.g. ươ no; ê in "iêu"=pos1; "uyê" pos 2; "oă"...).
 3. else if group contains horn/breve (hookPos!=-1): for uhoh, uhohi, uhohu (ươ, ươi, ươu) -> 1 (the ơ); else hookPos (e.g. "ưa"->0, "uơ"->1, "oă"->1, "ơi"->0).
 4. else len==3 -> 1 (middle: oai->a, uay, ioi.. e.g. "oai" tone on a, "uyu" y).
 5. else (2 vowels, no marks): modernStyle && group in {oa, oe, uy} -> 1 (hoá, khoẻ, tuý); else classic: `terminated ? 0 : 1` where terminated means no final consonant follows the group yet. So classic: "hóa","tùy","mía","múa","của","lúa","gái"? (ai ao au ay ia ie iu oi ua ue ui uo uu all: first vowel when open syllable; second vowel when a final consonant exists: "hoán","bạc"? single; "tiến" has roof). Tone position is recomputed with terminated=true when a vowel is typed/removed (cluster change) and with terminated=false when a final consonant is appended; move the tone char accordingly (the tone is stored on the vowel letter; moving = clear old index, set new index).
 NOTE qu/gi: since u in qu and i in gi are consonants, vowel group excludes them: "quá" a gets the tone, "gìa"->"già" ("gi"+"a": tone typed on gi is moved to a when vowel arrives; "gỉ" "gìn": tone on the i of gi/gin is allowed when the word is only the consonant cluster "gi"/"gin").
 processTone: no word/vowel -> plain append (tone key becomes a letter). Cases: form c with cseq gi/gin -> put tone on that i (position = last char for gi, one before for gin); same tone again -> remove tone + append raw key + reverted; tone0 on toneless -> append. Otherwise needs a vowel group: if spellCheck && !freeMarking && group incomplete -> plain append. With a final consonant c, ch, p, t: tones 2,3,4 (huyền hỏi ngã) are refused (append plain; "hoc" + 'f' stays "hocf"). Tone goes to tonePos = vowel group start + getTonePosition(group, terminated = (vowel group ends the word)). If the same tone is already there: toggle off = tone removed, key appended raw, reverted (this is the "ss" -> "s" and "ff", "rr", "xx", "jj" undo; tone0 (z) removes any tone, when none -> plain append). Different tone replaces it (wherever it was placed).
 Double-key undo summary: tone, roof, hook, dd all share the pattern "second press of the same event on an already-modified target: revert the mark, then append the pressed key as a literal letter, set reverted=true, singleMode=false". A third press then just re-appends letters (no re-apply because the state is now plain+letter; e.g. aaa -> "aa", aaaa -> "aaa", ssss -> "ss"+... careful: "ass"+ s appends letter).
3.6 dd: Dd event: if current entry is a lone nonVn 'd' (e.g. abbreviations after a non-vowel) -> becomes đ as a single-letter word and singleMode=true (spell check off for the word; many abbreviations start with dd). Normal path: the initial cluster must begin with d (c1Offset exists) and freeMarking must be on or the d must be the last char; d -> đ (singleMode=true: "never spell check a word starting with dd"); đ -> d + raw 'd' (undo, reverted, singleMode=false). A 'd' inside a longer initial like "dz" does not apply. Free marking: "dadd"... works because dd targets the initial of the word regardless of position ("dod"+"d"?? no: d key hits the word's first-consonant d; requires the initial cluster to be exactly d/đ).
 processNoSpellCheck: see 3.1.
3.7 backspace (processBackspace): if the previous entry is empty/nonVn/c/vc/cvc or this is the only char, simply pop one char (host does the delete; engine only returns handled if more than one backspace needed). Else (inside a vowel group): pop the last vowel; if there is a tone and the vowel group shrank so its tone position changed (computed with terminated=true) then move the tone to the new position (rewrite: backs + new text). Also pop the raw-keystroke buffer and, on reaching a word break, rewind to the previous word-break key. 
3.8 Word end (a WordBreak char): macro expansion first (3.9). If spellCheck off or singleMode or no word or restoring -> just append the break entry. Else if autoNonVnRestore && lastWordIsNonVn && lastWordHasVnMark (any tone/mark in the word) && at least one keystroke of the word was actually converted: restoreKeyStrokes: delete the whole rendered word (backs = word length) and type the raw keystrokes of the word as typed (the raw buffer from the last word break), then the break char; the word is re-fed through processAppend as plain symbols with restoring flag so it does not re-run transforms. The same restoreKeyStrokes is exposed as an explicit hotkey (output type UkKeyOutput = the host should type keys, not chars).
 lastWordIsNonVn: form nonVn -> true; empty/c -> false (lone consonants never "wrong"); v/cv -> !vowelGroup.complete; vc/cvc: group incomplete -> true; !isValidCVC -> true; or tone on the vowel group (with terminated=false) is 2,3,4 with final c/ch/p/t -> true.
 lastWordHasVnMark: any tone or any mark (circumflex, breve, horn, đ: i.e. letter != its StdVnRootChar) in the word.
3.9 Macro matching at word end (and Enter on Windows): bypassed if Shift+Space/Enter. Build the key from the buffer: scan back from the cursor up to MAX_MACRO_KEY_LEN(16) chars; first try the key starting after the previous word break (the word itself), then (if a break exists) the key including that break char (so macro keys can start with a symbol); lookup is case-insensitive (fold upper->lower on the standard letters). Case adaption: if the typed key's first letter is lowercase -> replacement text lowercased fully; if first letter is UPPER and all other typed letters are also upper -> text upper-cased; first upper but later lowercase (Title) -> text unchanged. Output: backspace over the matched key, type the replacement (converted to the active output charset) then the break char; buffer reset.

4. MACRO TABLE
====================================================================
Text file, UTF-8 (since version 1). Header line (first line; Windows writes BOM + ';' prefix): `;DO NOT DELETE THIS LINE*** version=1 ***` (non-Windows without BOM/';': `DO NOT DELETE THIS LINE*** version=1 ***`). Reader: skip optional BOM, find "***", then `version=%d`; no header = version 0 = legacy VIQR-encoded file (read as VIQR, then auto-rewritten as v1 UTF-8). Each following line: `key:text` split at the FIRST ':' (so text may contain ':'), CR/LF stripped, key truncated to 15 chars, text up to 1024, max 1024 items, 128 KB total memory. Stored sorted by key with case-folding comparison (qsort/bsearch on standard-char arrays), writer emits `key:text\n` lines without trailing newline on the last. Duplicates: both kept, bsearch returns one. Lookup key = the composed Vietnamese word as typed (tones/marks included). Replacement text may contain any Vietnamese; case adaptation per 3.9.

5. CHARSETS AND CONVERSION
====================================================================
Ids (vnconv.h): 0 UNICODE (UCS-2 LE words), 1 UNIUTF8 (UTF-8), 2 UNIREF (&#D; decimal NCR), 3 UNIREF_HEX (&#xH;), 4 UNIDECOMPOSED (Unicode combining/NFD, "UNI-COMP"), 5 WINCP1258 (composite + precomposed tables), 6 UNI_CSTRING (\uXXXX escapes in C strings; the only charset where the engine returns "handled" for every plain letter, others return pass-through for plain letters), 7 VNSTANDARD (internal hub), 10 VIQR, 11 UTF8VIQR (UTF-8 text with VIQR sequences allowed on input), 12 XUTF8 (x-unikey UTF-8 output: same as UTF-8; backspace count = char count like UNICODE), single-byte: 20 TCVN3, 21 VPS, 22 VISCII, 23 BKHCM1, 24 VIETWARE_F, 25 ISC; double-byte: 40 VNIWIN, 41 BKHCM2, 42 VIETWARE_X, 43 VNIMAC. CharsetIdMap names for the CLI: BKHCM1 BKHCM2 ISC NCR-DEC NCR-HEX TCVN3 UNI-COMP UNICODE UTF-8 UTF8 UVIQR VIETWARE-F VIETWARE-X VIQR VISCII VNI-MAC VNI-WIN VPS WINCP-1258.
Approach: hub-and-spoke through StdVnChar. Each charset implements `nextInput(bytes) -> StdVnChar` and `putChar(StdVnChar) -> bytes`; VnConvert(in,out) = decode all to std chars then encode. Details:
- Single-byte charsets: SingleByteTables[charset][213]: byte for each std index (0 = unused slot because that code point is occupied by a western symbol in the legacy charset, so the symbol is passed through; bytes not used by Vietnamese letters decode to themselves). Unmappable output -> pad '#'.
- Double-byte (VNI etc.): UKWORD per std index: low byte = base letter byte, high byte = tone mark byte (0 if none); output low then high. Input: a lone byte is a char unless in the table; two-byte lookahead for letter+tone.
- WinCP1258: Windows 1258 has base letters + 5 combining tone bytes: output uses precomposed code where the code page has one (WinCP1258Pre) else base + combining mark (WinCP1258 composite table).
- Unicode composite: letter + combining mark (0300 0301 0303 0309 0323, 0302/0306/031B for decoration) for decomposed input/output; input parses runs.
- VIQR: letters + ASCII marks: tone ' ` ? ~ . after the vowel, ^ ( + * decorations, DD/dd for đ; \ escapes; output escapes ambiguous text with a set of context patterns ("://", "/", "@", "mailto:", "email:", "news:", "www", "ftp") and by smart-VIQR option; options struct VnConvOptions{viqrMixed,viqrEsc,toUpper,toLower,removeTone,smartViqr}.
- Backspace accounting (getSeqSteps) for the engine: UNICODE and XUTF8 -> 1 per char; everything else -> encoded byte length of the char (apps delete by bytes in these charsets); UNIDECOMPOSED -> bytes/2.
OhKey recommendation: Unicode NFC precomposed output only in the engine (backs = chars); keep legacy charsets in a separate converter crate using the std-index hub; generate the tables from data.cpp (SingleByteTables lines 96-242, DoubleByteTables 244-342, WinCP1258 343-394, VIQR/UnicodeComposite 441-520) by a script rather than retyping; copying them makes that crate GPL-2.0+.
